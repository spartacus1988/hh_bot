# HH Bot

Android-приложение (Android 10+, minSdk 29), которое работает как «Selenium для телефона»:
находит установленное приложение hh.ru, запускает его, открывает экран поиска,
вводит запрос по одному символу (как человек) и нажимает «Найти».

## Что умеет сейчас

1. Ищет hh.ru на устройстве (`ru.hh.android`, резервные варианты — по имени пакета/метки).
2. Запускает приложение hh.ru.
3. Через `AccessibilityService` читает дерево интерфейса:
   - закрывает стартовые шторки («Пропустить», «Позже», «Закрыть»);
   - находит строку поиска (`EditText` с подсказкой «Профессия, должность или компания»)
     либо кнопку «Поиск вакансий» на главном экране и открывает экран поиска;
   - вводит `embedded-программист` посимвольно с паузами 70–160 мс;
   - нажимает кнопку «Найти» / «Искать» / иконку поиска (с запасным вариантом
     `ACTION_IME_ENTER` на Android 11+ и «человеческим» тапом через `dispatchGesture`).

## Сборка

### Вариант 1: готовый скрипт (без Gradle)

```powershell
powershell -ExecutionPolicy Bypass -File .\build-apk.ps1
```

Результат: `hh_bot.apk` в корне проекта.

Скрипт использует JDK 17 и Android SDK 34 из `E:\android\toolchain`
(пути можно переопределить переменными `JAVA_HOME` и `ANDROID_HOME`).
Ключ подписи создаётся один раз в `keystore/hhbot.keystore`
(пароль `android`) — не удаляйте его, иначе обновление APK потребует переустановки.

### Вариант 2: Android Studio / Gradle

Откройте папку проекта в Android Studio и соберите `app` (AGP 8.5.2, JDK 17).

## Установка

```bash
adb install -r hh_bot.apk
```

Либо скопируйте `hh_bot.apk` на телефон и установите вручную
(разрешите установку из неизвестных источников).

## Первый запуск

1. Откройте **HH Bot**.
2. Нажмите **«1. Включить службу доступности»**.
3. В настройках Android найдите **HH Bot** (раздел «Специальные возможности» /
   «Accessibility») и включите службу. Android покажет предупреждение — это нормально
   для любого приложения-автоматизатора.
4. Вернитесь в HH Bot. Статус должен стать зелёным.
5. Нажмите **«3. Запустить hh.ru и выполнить поиск»**.
6. Не блокируйте экран: hh.ru откроется, в поле поиска появится
   `embedded-программист`, затем будет нажата кнопка поиска.
7. Ход выполнения виден в журнале внутри приложения; в конце появится всплывающее
   сообщение об успехе или причине ошибки.

> На Android 13+ для приложений, установленных не из Play Store, переключатель
> службы доступности может быть неактивен. Тогда откройте «Настройки → Приложения →
> HH Bot → меню (⋮) → Разрешить ограниченные настройки» и включите службу снова.

## Ограничения

- Работает только когда экран включён и hh.ru на переднем плане.
- Если hh.ru при первом запуске показывает вход/онбординг с нестандартными кнопками,
  пройдите его вручную и повторите запуск.
- Автоматизация через Accessibility зависит от версии hh.ru: тексты кнопок и структура
  экранов могут отличаться. Все эвристики собраны в `HhAccessibilityService`
  (`findSearchField`, `findSearchEntry`, `findSubmitButton`) — их легко расширить.
- Приложение не отправляет данные в сеть и не связано с hh.ru.

## Структура

```
app/src/main/java/ru/hhbot/
  MainActivity.java              — экран, настройки, запуск сценария
  HhAccessibilityService.java    — автомат: поиск окна, ввод текста, нажатие «Найти»
  AppFinder.java                 — поиск установленного hh.ru
  BotLog.java                    — общий журнал
app/src/main/res/xml/accessibility_service_config.xml
app/src/main/AndroidManifest.xml
build-apk.ps1                    — сборка APK без Gradle
```
